常见问题

按"现象 → 先查什么 → 怎么解决"组织。

装不上 / 看不到

功能区没有「动画曲线」选项卡

先跑一遍自动体检，它会把下面这些步骤一次性查完：

npm run doctor

输出会逐项打勾，哪一步断了直接看对应那行的提示。

手工排查的话，按顺序：

WPS 里必须有文档打开。 空窗口（启动页）不加载任何加载项——这是 WPS 的行为，不是插件的问题。打开一个 pptx 再看。

如果还是看不到，按顺序排查：

  1. 安装配置在不在：%APPDATA%\kingsoft\wps\jsaddons\publish.xml 文件里应该有 name="WpsCurveAnim" 和一条 url
  2. 发布地址能不能访问：浏览器打开 <你的地址>/ribbon.xml，应该看到以 <customUI 开头的文本 —— 打不开的话 WPS 也拉不到，插件必然不出现
  3. 是不是个人版老版本：个人版需要 ≥ 12.1.0.16910，更老的版本不支持 publish 模式

装完必须重启 WPS

publish.xml 只在 WPS 启动时读一次。改完配置、更新过加载项，都要完全退出 WPS 再开。

任务窗格同理：面板是常驻页面，关掉再打开可能还是旧缓存，重启最保险。

Mac 上装不了

WPS 的加载项机制目前只适配 Windows 和 Linux，Mac 版没有。这不是我们的选择。

面板能用但不好用

控制点拖不动

先看面板顶部「精确输入」——展开后可以直接填 x1 / y1 / x2 / y2 四个数， 这条路完全不依赖鼠标事件，任何环境下都能改曲线。

拖拽失败通常有两个原因：

  • 点歪了：只有曲线两端的两个蓝点可以拖，曲线中段不行。窗格窄的时候蓝点视觉半径只有 3px 左右
  • 命中范围：代码里给了 46px 的命中半径（画布坐标），实际点周围一小圈都能抓住

预设点了没反应？其实拖一下更自由

那排「线性 / 缓入 / 缓出…」只是快捷方式。直接用鼠标拖蓝点就是自定义曲线，拖完预设高亮会消失。

面板太窄，按钮挤成两行

WPS 任务窗格默认宽度大约 270~330px。把窗格边缘往外拖一点会更舒服， 面板本身在 200px 宽下也能用（会自动隐藏提示文字、缩小标签）。

写了动画但效果不对

点了「应用」形状没动

三件事按顺序看：

  1. 面板顶部状态栏写的是「未选中形状」还是「已选中 N 个形状」？ 没有选中时，从「目标」下拉框里直接选形状即可，不必在画布上选
  2. 幻灯片的「动画」窗格里有没有多出一条？没有的话说明写入失败，面板状态栏会显示错误
  3. 放映时是不是还停在这一页等点击？把「时机」改成「进页自动播」再试

动画跑的方向跟想的不一样

起点和终点是按顺序用的：形状从绿点走到蓝点。 如果看起来是倒着走的，多半是把两个点拖反了——把绿点（起点）和蓝点（终点）对调即可。

做入场动画时，终点应该在形状的原位（点一下「= 形状位置」最省事），起点拖到画面外。

形状在播放前就露在终点位置了

入场动画（起点在别处、终点是形状原位）+「单击时」时可能出现： 效果播放前形状本应隐藏，如果它已经停在原位，点一下会先"闪现"再滑动。

规避：把「时机」改成「进页自动播」。 延迟几乎为零，看不出问题。

想复现或确认这个行为，仓库里有一份现成的检查文件 test/entrance-check.pptx： 打开 → F5 放映 → 什么都别按 → 看那个品红方块在不在原位。

动画和原生动画打架

本工具是新增一条动画，不会修改你已有的动画。同一个形状上如果既有一条原生"飞入"、 又加了一条本工具的位移，两条会叠加——位移量会翻倍。

需要改已有的原生特效速率？做不到：p:animEffect 只有 accel/decel 两个百分比， 不存在关键帧表（详见 README 的「能做 / 不能做」）。

形状跑到画面外了

小图上的点是可以拖到版心边缘之外的（数值会显示成负值或超过 100%）， 这时形状确实会飞出画面——这是预期行为，不是 bug。拖回来就好。

分发相关

github.io 打不开

github.io 在国内经常不可用。而加载项每次启动都要从发布地址拉文件， 地址不通 = 插件白屏或不加载。

换 Gitee Pages / Vercel 托管 docs/ 即可。换完重跑：

npm run release https://新地址/addon/

安装页里的地址会跟着更新。

更新后还是旧版本

三层缓存都要考虑：

  1. 浏览器缓存 → 强制刷新
  2. GitHub Pages 缓存 → 等 1~2 分钟
  3. WPS 侧缓存 → 重启 WPS

怎么卸载

删除 %APPDATA%\kingsoft\wps\jsaddons\publish.xml，重启 WPS。

如果是通过公开安装页装的，也可以打开安装页点「卸载」。

装不上或行为异常，先跑 npm run doctor 做一次环境体检。
